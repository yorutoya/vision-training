# 代码理解与验收问答

按 `main → preprocess → runModel → decode → estimatePose` 阅读，先看数据怎样流动，再看库接口。

## 一帧如何处理

main 读取图像；preprocess 生成模型输入与缩放参数；runModel 执行一次推理；decode 筛选、恢复坐标并去重；estimatePose 求三维角点；main 写出一行 JSON。
模型只在循环外加载一次。没有目标的帧仍记录帧编号、时间和空 detections。

## 常见提问

1. 为什么等比例缩放后补边？直接拉伸会改变物体比例。补边保留几何关系，之后能通过减补边、除缩放比例恢复原图坐标。
2. 为什么 RGB、CHW、float16？这是提供模型的输入约定。OpenCV 原始图像是 BGR 交错排列，需要显式转换。
3. Ort 是什么？ONNX Runtime 的 C++ 命名空间。Session 加载模型，Run 执行推理，加载模型不等于推理。
4. confidence 怎么算？输出第 8 个值是 logit，使用 sigmoid；不乘类别分数。正负分支是为了避免 exp 溢出。
5. 为什么需要 NMS？同一块板可能有多行候选，用四角点包围框的 IoU 抑制重复结果。
6. 角点如何恢复？x=(模型x-padLeft)/scaleX，y=(模型y-padTop)/scaleY。比例用实际整数缩放尺寸计算。
7. 为什么不重新排序角点？模型点与物理点必须一一对应，画面旋转不应改变装甲板自身的点编号。
8. 装甲板大小怎么选？根据图案类别，不能根据 small.mp4/large.mp4 文件名选择。
9. PnP 输入是什么？物理角点（米）、图像角点（原图像素）、相机内参、畸变。
10. PnP 输出是什么？物体到相机的旋转和平移。t 只是物体原点，四角点必须分别计算 R×P+t。
11. 为什么选 IPPE？四点共面。IPPE_SQUARE 要求正方形，本题是长方形。
12. 多解怎么选？先检查数值有限且四点在相机前方，再选重投影误差最小者；没有做时序消歧。
13. 重投影误差怎么算？投影回原图，与检测角点比较，四点欧氏误差平方和除以 4，再开方。不是除以 8。
14. PnP 失败怎么办？保留二维检测，三维和误差填 null，继续处理视频。
15. 如何检查结果？抽帧看四个点是否贴合灯条端点，观察重复框、漏检、类别和异常三维深度；检查 JSONL 是否 360 行、编号和时间连续。
16. 为什么不能声称准确率？没有逐帧人工标注真值；候选数量、重投影误差和视觉抽查不能替代准确率测量。

## 动手练习

- 在 preprocess 中打印 scaleX、scaleY、padLeft、padTop，解释为什么当前视频上下各补 80 像素。
- 将置信度从 0.5 改为 0.7，重新运行并比较数量与漏检，实验后恢复基线。
- 在 decode 中暂时打印 NMS 前后数量，找一帧解释哪些候选被抑制。
- 手算一个点从模型坐标 (320,320) 恢复为原图 (720,540)。
- 找一个 JSON 检测，说明四个相机坐标为什么不应完全相同。

不要只背问答：能找到对应函数，修改一个参数，解释输出为何变化，才算理解。
